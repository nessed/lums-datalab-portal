How a figure gets on this site

  1. Read from the official PDF by a table-extraction tool. No language model writes a number or decides whether it passes.
  2. Checked by fixed rules: sums, accounting identities, the same figure in another edition.
  3. Published only if it passes. Otherwise a labelled gap that says why.
