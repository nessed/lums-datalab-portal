# Home v2 and v3 design: what the release cannot supply

2026-11-23. Branch `proto/home-v2-2026-11`. The design files are pictures, not a
data source: no number, page reference, date or chart point was copied from
them. Every figure on the built pages is read from the release through `db()`
and shown with `V`, `Num` or `Count`; every sum, change or share is a derived
figure that a plug-in under `site/scripts/checks/` recomputes.

The slots below are in the design but the current release (ABS, CPI and LFS
data only) cannot fill them. Each one is left out or shown as a labelled gap.

| Design slot | Screen | What the build does | What would fill it |
|---|---|---|---|
| Today's rates (petrol, dollar, gold and the rest) and their history | Home v2, v3 | Names only, marked "Not yet collected" (flag `dailyRates` off) | A daily-prices collection (planned, not built) |
| Urdu names and the Urdu link in the header | Header, Home | Left out | Urdu pages and checked translations |
| Province share of the national labour force | Home: Your province | Left out; the province rows show only figures the release holds | LFS provincial totals in the release |
| Rs 100 paisa rows as drawn | Home: Where Rs 100 goes | Rows computed from the federal budget functions in the release (`home-per100`) | Nothing: the design's rows are not used |
| Chart values and sparklines | Home, Dataset | Drawn from the release series only | Nothing |
| Every provincial budget figure | Compare provinces | Gap state: "not yet collected" for each province | Provincial budget books in the release |
| CPI index values before the 2015-16 base (the design's 2016-2019 values) | Inflation calculator | The calculator covers only periods on one base (2015-16 base, 2020-06 to 2026-06); no splicing across bases | A published linking factor between bases |
| "21 series" and other counts in the design | Find data, What's new | Counts recomputed from the release (`Count`) | Nothing |
| Dates and values in the What's new entries | What's new | Built from the release's own version history and source documents | Nothing |
| Rupee value result on the home page | Home v3 | Left out; links to the inflation calculator | Nothing: the sum is shown on the calculator page with its inputs |
| The map of provinces | Home, Compare provinces | Left out | Boundary files and province figures for every slot |
| Daily-rate "change since yesterday" | Home v3 | Left out | The daily-prices collection |
| Actual (accounts) figures beside budget and revised estimates | Home v3 budget feature, Dataset, Guides | Labelled gap: "Not yet collected" / "not in this release" | Federal accounts in the release |
| Chart image download and printed-pages download | Dataset | Labelled "not in this release yet" | A chart renderer and page extracts |
| "Figure type" filter | Find data | Left out | A figure-type key in `site/scripts/checks/facets.mjs` (shared with check-build) |
| "Latest from <document>" line and the State Bank EasyData advice | Find data | Left out | Nothing in the release fills them |
| Short value and page reference in rows the browser filters | Find data | Rows drawn after filtering show the full value and period only | Short value and page in `/catalogue.json`, checked by `catalogue-json.mjs` |
| Dates in words ("23 November") | What's new | Dates shown as YYYY-MM-DD (the `Num` date kind) | A worded date kind in check-build |
| Urdu province names | Compare provinces | Left out | An Urdu font token and checked names |
| Calculator months other than June | Inflation calculator | June only, the one month present in every year | Every monthly CPI issue in the release |
