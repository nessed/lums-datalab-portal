# Fault injection on the published values

Release: `releases/v0.0.1-prototype`. Generated by `pipeline/scripts/fault_injection.py`; the release is not changed.

For each published value, one wrong copy per fault is made, the sums and equalities it belongs to are recomputed, and the status rule is applied. An *escape* is a wrong value that would still be published as checked. This measures what the checks can see; it is not the portal's error rate (that needs the gold set). Sums, equalities, reference weights, cross-source checks, recomputed rates and index aggregations are redone from the changed value; where a recompute formula could not be reproduced the stored result is kept and the escape is counted as not simulated. Only value faults are injected: lost columns, merged cells and wrong row mapping are other failure modes.
